PHUZZ_EXPANDED experiments
======================

This folder contains data and results for the different experiments performed with PHUZZ_EXPANDED.

## 01 Known vulns

This folder contains the results for the evaluation of PHUZZ_EXPANDED vs. the other fuzzers against bWAPP, NoSQL, Testsuite and XVWA.

## 02 0day vulns

This folder contains the data and results for the evaluation of PHUZZ_EXPANDED against WordPress plugins.
